# Expansion assessment criteria

Fixed before changing the skill. All prompts are synthetic and are in [expansion-prompts.json](expansion-prompts.json). Assess actual outputs, not exact wording. Record limitations and failures without converting prose quality into an objective numerical score.

| ID | Observable criteria |
| --- | --- |
| S1 | Detect preparation and salt conflicts, duplicate/missing labels, absent central control, missing methods and unverified code availability; follow supplied SI/data packaging; do not select conflicting facts or invent details |
| A1 | Follow award contribution/impact criteria; distinguish personal pipeline work from PI/lab leadership; preserve accepted/preprint status; avoid fabricated impact; deliver no more than 100 words plus separate support gaps |
| A2 | Separate applicant development from project science; correct host commitment and completed-assay claims; tie learning to proposed host fit without asserting agreement; respect final-applicant authorship requirement |
| A3 | Deliver distinct abstract and travel texts; retain measured preparation/condition scope and pending acceptance; avoid fabricated need/costs; identify missing need evidence; count words accurately and remain within both limits |
| A4 | Allocate distinct functions to requested package components; preserve TA/mentoring role and proposal status; avoid invented teaching results, independence, or collaboration; align proposed teaching with the supplied role |
| P1 | Use the journal's soundness criteria; distinguish particles from independent preparations; bound generality and statistics; identify missing materials without alleging they do not exist; make actionable major/minor concerns and a justified advisory recommendation in a separate editor section |
| P2 | Use only supplied criteria and rating labels; do not penalize absence of explicitly optional preliminary data; evaluate dependency, milestone and fallback weaknesses; remain prospective and tie the rating to evidence |
| E1 | One grammatical correction, preserves submitted/unaccepted status and contribution, no unsolicited review or workflow |
| R1 | Answer both concerns, verify only the excerpt, keep kinetics pending, invent no analysis/edits/locators |
| E2 | One grammatical correction to the review, preserves minor-revision judgment, no new assessment or editorial decision |

Compare the original and revised skill using independent executions of the same prompts. Any comparison is limited to these executions and is not an estimate of general effectiveness, model differences, or publication outcomes.

Observed outputs: [original skill](expansion-baseline.md) and [revised skill](expansion-candidate.md). Execution-record paths are normalized for portability; task outputs are preserved.

The [independent assessment](expansion-assessment.md) checks both versions against these criteria and independently verifies requested word counts.
